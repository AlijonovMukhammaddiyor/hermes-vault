### Lesson: The Transformer — What Your Agents Run On

You're building AI agents. Every agent you'll ever design runs on a transformer. If you can't draw the attention mechanism from memory and explain why decoder-only won, you're building on sand. This isn't trivia — it's the substrate every architectural decision sits on.

**Start here: the mental model, not the math.**

A transformer does one thing: it looks at a sequence of tokens and figures out which ones matter to each other. That's attention.

Here's the stripped-down version you need to carry in your head:

*Tokens go in* → each token gets three learned projections: **Q**uery, **K**ey, **V**alue. Think of it as:
- **Q**: "What am I looking for?" (each token asks: who's relevant to me?)
- **K**: "What do I offer?" (each token announces: here's what I contain)
- **V**: "Here's my actual content." (the information to pass forward)

The magic: Q·Kᵀ (scaled) → softmax → multiply by V. Every token attends to every prior token — weighted by relevance. That's **self-attention**. One pass, all tokens, no sequential bottleneck.

**Multi-head**: do this 8–64 times in parallel with different projections — different heads learn different relationships (syntax, semantics, position). Concatenate, project back down.

**Why residual connections + layer norm everywhere**: the gradient needs a highway through 80+ layers. Residuals are that highway. Layer norm stabilizes the numbers so training doesn't explode.

**Positional encoding**: attention is permutation-invariant — it doesn't know order by default. You inject position information so "The cat sat" ≠ "sat cat The."

**Decoder-only vs encoder-decoder**: GPT-style models are decoder-only — each token can only attend to itself and prior tokens (causal masking). Why? Because (a) it's simpler, (b) it's what you need for autoregressive generation, and (c) the Bitter Lesson says: the approach that scales wins. Encoder-decoder adds complexity that doesn't buy enough at scale.

**The Bitter Lesson** (Sutton, 2019): every hand-crafted structure we bake in eventually gets beaten by general methods that leverage more compute. For agents, this means: the scaffolding you build today may be obsolete when the next model drops. Build harnesses that survive model upgrades.

**Why context windows matter for agents**: your agent's entire "working memory" is the context window. KV-cache cost scales with it. Every tool call, every retrieved chunk, every conversation turn eats tokens. This is why context engineering — not prompt engineering — is where reliability is won or lost. More later; for now, know that the context window IS the agent's brain.
