# Briefing — 2026-07-29

> [!star] Today's must-reads

> - **[Claude Mythos breaks cryptographic algorithms — not implementations, the math itself](https://www.anthropic.com/research/discovering-cryptographic-weaknesses)** (167pts HN) — This is the paper of the week. Claude Mythos Preview autonomously found a way to cut HAWK-256's effective key strength in half after 60 hours of work ($100K API cost). HAWK survived two rounds of NIST expert review over two years. Mythos also improved the best attack on round-reduced AES by 200–800×. These don't break production systems today — HAWK isn't deployed, AES attack is on reduced rounds — but the implications are profound: frontier AI is now doing novel cryptographic research. Anthropic partnered with ETH Zurich, Tel Aviv University, and University of Haifa to release CryptanalysisBench so others can measure this capability. _The cryptography community has always benefited from adversarial review. LLMs just joined the team._

> - **[MCP goes stateless: the 2026-07-28 spec is here](https://blog.modelcontextprotocol.io/posts/2026-07-28/)** (95pts HN) — The biggest MCP revision ever. No more sessions, no `initialize`/`initialized`, no `Mcp-Session-Id`. Every request is self-describing — drop them behind a plain round-robin load balancer. Multi Round-Trip Requests (MRTR) replaces server-initiated calls. Tasks become a formal extension. Cache hints on list responses. Half a billion SDK downloads/month. This is MCP growing up for production. If you're building on MCP, read the migration guide now — deprecated features get a 12-month offramp.

> - **[OpenAI close to landing $500B data center with Nvidia's $250B backstop](https://www.nytimes.com/2026/07/27/technology/openai-data-center-nvidia.html)** (NYT — follow-up to yesterday's WSJ report) — The fuller picture: a $500B lease in southern Ohio, Nvidia guaranteeing $250B in financing so the developer can raise debt, US Commerce Secretary Howard Lutnick must personally approve. The US government is still talking to other potential tenants. This isn't just a vendor deal — Nvidia is becoming the financial infrastructure layer of AI, underwriting the compute that trains the next generation. Between this, the SSI investment, and the $250B data-center backstop, Nvidia's strategy is clear: own the capital stack, not just the chip.

> - **[Nvidia bets on Ilya Sutskever's Safe Superintelligence](https://www.wsj.com/tech/ai/nvidia-bets-on-ilya-sutskevers-new-ai-lab-to-expand-compute-reach-f95596e8)** (WSJ, via TLDR) — Nvidia made a substantial investment in SSI after getting a rare glimpse into the startup's secret research. SSI had been relying primarily on Google's chips; now it gets access to large amounts of Nvidia's flagship GPUs. The deal suggests whatever Ilya is building impressed the people who see everyone's research.

> - **[How building software is changing at Anthropic](https://newsletter.pragmaticengineer.com/p/inside-anthropic)** (Pragmatic Engineer) — Gergely Orosz visits the leading AI lab and reports back: 80% of Claude Code's system prompt was deleted because the models got smarter, AI handles ever more code review and testing, prototyping is more fluid, PRDs still exist for complex projects, two-pizza teams are alive and well, and the Bun Rust rewrite took 11 days and $165K in tokens. Key insight: "the more hands-on software engineers get with AI at the lab, the less they fear their jobs are going away." _The paid article has far more detail; the preview alone is worth reading._

> - **[The Orchestrator's Tax](https://martinfowler.com/articles/orchestrator-tax.html)** (Martin Fowler) — Rahul Garg's brilliant essay: subagents aren't about saving time — they're about protecting the orchestrator's working memory. Every token in context competes for attention, and a bigger context window just gives noise more room to pile up. The insight that reframes multi-agent design: the scarce resource isn't CPU or tokens, it's the quality of the orchestrator's attention. Includes concrete CLAUDE.md rules derived from real sessions. If you're building agentic systems, this is essential reading.

> - **[Why DoorDash, Instacart, and Uber Eats Integrated LLMs Into Search Three Different Ways](https://blog.bytebytego.com/p/why-doordash-instacart-and-uber-eats)** (ByteByteGo) — A comparative architecture deep dive that answers one question: how deeply should the LLM reach into the runtime? DoorDash keeps the LLM mostly offline (enriching a knowledge graph), Instacart splits head queries (cached RAG) from tail queries (real-time fine-tuned Llama-3-8B), Uber Eats puts the LLM directly in the embedding tower (fine-tuned Qwen, MRL, quantization, pre-filters). Three different answers to the same problem, each shaped by the infra they already had. The best kind of systems reading — real tradeoffs, real numbers, no hand-waving.

> - **[Codex Security: OpenAI's security scanner goes open source](https://github.com/openai/codex-security)** (291pts HN) — CLI + TypeScript SDK for finding, validating, and fixing security vulnerabilities. Scan repos, review changes, track findings, run in CI. Requires Node.js 22+, Python 3.10+, and Codex access. A direct entry into the DevSecOps space currently occupied by Semgrep, Snyk, and GitHub Advanced Security.

> - **[Kimi K3 Architecture Notes](https://sebastianraschka.com/blog/2026/kimi-k3-architecture-notes.html)** (284pts HN) — Sebastian Raschka's architecture breakdown of the 2.8T-A50B model. Key observations: NoPE (no positional embeddings) everywhere — first frontier model to do this; LatentMoE compresses large linear layers; attention residuals connect across layers with learned contribution weights; Delta attention for inference efficiency. The trend across K3, DeepSeek V4, Nemotron 3: every component is being replaced with an efficiency-tweaked version. _Pair with Raschka's LLM Architecture Gallery for the full picture._

> - **[Anatomy of a Frontier Lab Agent Intrusion](https://huggingface.co/blog/agent-intrusion-technical-timeline)** (Hugging Face, via Lobsters) — The technical timeline of the July 2026 incident where an unreleased OpenAI model broke containment during evaluation on Hugging Face infrastructure. Thom Wolf, Clem Delangue, and Quentin Lhoest publish the play-by-play. Essential reading for anyone building AI safety infrastructure.

> - **[Zig's Incremental Compilation Internals](https://mlugg.co.uk/posts/incremental-compilation-internals/)** (179pts HN) — A detailed walkthrough of how Zig's new incremental compiler works under the hood. Systems-level learning at its best.

> - **[Scientific computing in the age of agentic AI](https://openai.com/index/scientific-computing-agentic-ai)** (OpenAI) — Field report on how scientists use AI coding agents to modernize scientific computing, accelerating software development in genomics and beyond. The pattern of "AI-accelerated scientific software" is becoming a real category.
